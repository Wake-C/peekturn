# 憩页

一个帮你把英文原版书读完的 Android 阅读器。

[English](README.md)

## 你完整读完过一本英文书吗？

不是分级读物，不是书摘，是一本真正的书，从第一页读到最后一页。

市面上的英文阅读 App 已经够多了。更多功能、更多翻译、更多课程、更多打卡，看起来什么都能做。但用了这么多之后，你的英文真的成长了吗？

词汇的成长，和对一个词的语感，不是靠收集定义得来的。它来自在真实语境里反复遇见同一个词，直到这个词的含义变成一种感觉，而不只是一条需要背诵的解释。

所以憩页只做最核心的几件事：

- 把书朗读出来；
- 记住一个词的核心含义；
- 理解它在这个上下文里的含义；
- 给出能说明用法的例句。

目的不是背完一个定义就翻页，而是从一个词的用法和文化里理解它，同时不停下来，继续把书读下去。

## 它做什么

- 通过 Readium 导入原始 EPUB 文件，也可以从 HTTPS 链接或 Android 分享导入文章。能拿到的标题和作者会保留；预览页和不可用文章不会当成导入成功。
- 保留 Readium 自己的排版与翻页，不用自定义分页器或扁平化章节文本。阅读位置使用 locator，不依赖页码，重启和调整排版后仍能回到原处。
- 选中单词或短语后给出上下文帮助：核心含义、当前语境中的含义和例句。Quick Explain 可以直接打开。
- 当完全相同的上下文、书籍或章节身份、界面语言和模型配置仍然匹配时，已完成的解释可以在 15 天内复用。设置里可以看到缓存占用并清除。
- 包含离线词典、在线单词和例句发音、系统语音兜底、美式或英式口音选择，以及可选自动播放。
- 从当前句子开始连续朗读，带播放、暂停、上一句、下一句、速度、停止和重试。锁屏后继续播放，句子音频私密缓存，可离线重听。
- 五套内置阅读字体，可调字号、字距、行距、段距和页边距；五套应用主题；界面语言可选跟随系统、English 或简体中文。
- 记录真实的前台阅读时长，支持空闲检测。没有编造的统计、示例书或演示答案。

## 它不做什么

- 不做整书翻译，也不把章节压平成纯文本。
- 不做背单词、闪卡或连续打卡。
- 不做云书库、账号或同步。
- 不放示例书库，不编造阅读数据。

## 构建与运行

需要 JDK 17 和 Android SDK platform 35。设置 `ANDROID_HOME`，或在未跟踪的 `local.properties` 中写入 `sdk.dir=...`。

运行检查并生成带 SHA-256 和构建凭据的版本化 debug APK：

```sh
./tools/package-apk.sh
```

这条命令需要 POSIX shell、Python 3 和 Git。输出、安装和失败处理见[交付手册](agent-doc/reference/delivery/RUNBOOK.md)。它不会改动源码或版本号，也不配置发布签名。

只构建 debug APK：

```sh
./gradlew :app:assembleDebug
```

debug APK 是通用包。macOS 上，如果未设置 `JAVA_HOME`，Gradle wrapper 会选择已安装的 JDK 17。其他平台请提供 Java 17。

## 隐私

书籍、进度、偏好和阅读统计都留在设备上。模型请求只包含选中的文本、有限的邻近片段和可用的书名或章节名。API Key 使用 Android Keystore 加密，应用备份已关闭。

单词和句子发音使用公开的免密钥服务。离开设备的只有你要求听到的那段文字，不包含周围书籍正文，也不包含凭据。离线词典不联系任何服务商。具体路由和署名见[产品说明](agent-doc/reference/SPEC.md)和[第三方声明](THIRD_PARTY_NOTICES.md)。
