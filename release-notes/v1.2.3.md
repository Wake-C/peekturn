## Changes

- Refresh all five themes with neutral paper and dark surfaces, blue-accent controls, and more readable secondary text.
- Make the library more compact with a horizontal continue-reading section, softer search field, and lighter status filters; reading statistics now give today's reading time more emphasis.
- Refine settings, appearance choices, reading sheets, and word-help popups with consistent typography, spacing, icons, and dividers.
- Restyle narration controls while retaining the existing previous, play/pause, and next actions and compact footer.

This is a visual update. Existing navigation, appearance selection, reading layout, speech providers, narration behavior, and saved books and preferences are unchanged.

Install `peekturn-1.2.3-9-release.apk` for Android 8.0 or later. The accompanying `.sha256` file can be used to verify the download.
