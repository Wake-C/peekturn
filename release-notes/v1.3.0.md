## Changes

- Prepare a whole book once for the current narrator voice, then play it offline with the existing reading position and sentence controls.
- Pause and resume preparation, including after closing the app; preparation can continue with the screen off.
- Keep a separate saved copy for each narrator voice. Saved audio survives clearing the temporary sentence cache.
- Choose live narration or saved audio from Listen. Starting live narration or pronunciation pauses preparation.

Existing book layout, library, settings, and the previous, play/pause and next controls are unchanged.

### Download

Install `peekturn-1.3.0-10-release.apk` for Android 8.0 or later. The accompanying `.sha256` file can be used to verify the download.
