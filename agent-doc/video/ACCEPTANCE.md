## 根因与实现决定

### 模型错误分类

真实测试接口曾返回 HTTP 402，并明确报告余额不足，旧代码却显示可能为 JSON 输出不兼容。现在 402 为 Balance，400/422 为 InvalidRequest，非流式内容或流信封协议错误为 Protocol，其他服务失败不再推测 JSON 不支持。英文与中文均有对应文案。

请求使用的接口地址、模型、JSON 输出格式、温度和流式设置没有被偷偷替换。没有解析、记录或直接显示服务商错误正文，不自动换模型或重试。

### 字幕语言与身份

默认顺序为英语人工、英语自动生成、源站明确支持的英语自动翻译。其他语言不再自动兜底；用户可手动选择。设置显示语言名称及人工、自动生成、翻译来源标记。

原始轨身份来自已请求的 YouTube player response 的 vssId，不再仅按语言与生成方式去重。翻译轨身份包含来源和目标语言，签名参数不进入持久身份。NewPipe 没有公开翻译语言列表，适配器只从当前解析已取得的 player response 提取必要元数据，解析结束即清理，不额外请求网页，不导入账号 Cookie。

只有源站同时标记该轨可翻译、目标语言包含英语时才提供英语翻译选项。翻译和字幕下载仍可能被源站拒绝，不能把选项存在当作获取成功。

DB v3 增加 `track_explicit`。升级时旧记录默认不是用户明确选择，避免旧版的自动韩文回退被永久恢复。之后的手动选择独立保存。书籍、位置、设置、凭据和统计不删除。

### 高清与切换

旧代码优先选带音频的合并流，测试视频的这种流只有 360p，虽然匿名解析已经能取得 1080p 的分离视频及音频。

现在提供源站实际返回的 progressive MP4 档位，不再用 720p 上限隐藏高清。默认选择不高于 1080p 的最高档；若所有实际档位更高，则选择其中最低档。相同高度优先合并流，其次优先 AVC；分离视频必须搭配真实 M4A，优先源站标记的原语言音轨。

切换复用同一个 ExoPlayer，保留位置、倍速、字幕与暂停所有权，不重新解析字幕。失败诚实显示播放错误，允许用户手动选择另一个现有档位；不自动循环重试。手动恢复还会重启真实播放位置采样。

未接入 Google 登录、学生会员或 Premium 格式。普通匿名高清不等同于会员增强码率，不因列出清晰度而承诺设备支持所有编解码格式。

### 首帧与字幕加载

仓储返回媒体会话时只读取已有字幕缓存，不等待字幕网络请求。播放器准备之后独立取得缺少的字幕。已有条目在解析时可先显示保存的标题，但不能冒充画面已可播放。

开发日志增加无内容的 source-ready-ms 和 first-frame-ms 数值，重试重新计时。它们只说明该次真实耗时，不承诺网络下的固定启动速度。一次调试包冷打开实测源会话约 7164ms，首帧约 15156ms；这是高清媒体准备时间，不是比旧版更快的同条件对照实验。

### 合并字幕

模型判断语义句界，本地程序控制时长、词数和停顿。先验证边界编号存在、递增、无重复且覆盖尾部，再沿原始 cue 边界拆分过长组。单个超限 cue 单独保留，不删词。未知、重复、乱序或不完整编号仍失败，不猜补缺失内容。

显示文本只能由原字幕构造，时间只能取源 cue。合并提示词版本为 caption-merge-v3，旧结果不会掩盖新规则。无变化的完整分区明确显示无需合并，不称为优化成功；开关关闭立即恢复原轨。

## A 布局的验收底线

竖屏画面上方、字幕下方；运输控件默认隐藏，点画面才显示固定底部工具。横屏上一句、播放暂停、下一句保持几何居中，时间和进度在底部。显隐不移动字幕。解释为独立浮层，横屏居中，不挤压视频或字幕。

本轮只在原播放设置中增加语言、翻译类型和真实清晰度选项，没有改成侧栏、浏览器播放器或其他 A/B 布局。320dp 矮横屏实测中央控件与字幕分离，解释关闭、重听可达。没有增加教学式点词提示或伪造逐词时间。

## 未验证范围与外部限制

用户尚未提供出现韩文且切不回英语的那条视频，不能声称完全复现并验证了该特例；本轮用实际多语言示例覆盖了默认策略和日语回英语的链路。

自动翻译在本机遇到源站 429，成功翻译正文没有通过本轮验收；只验证了真实能力枚举、请求构造、失败状态和切回原轨。不能用伪字幕或模型翻译代替它。账号登录、Premium 专属流和所有厂商的 TLS/解码行为均未实现或穷举。

没有实体手机人工听音或真人访谈，也没有直接操作用户的一加 VPN。原来的重定向循环、后来的 TLS EOF 和服务商余额失败分别处理，不声称诊断日志本身修好了网络。
