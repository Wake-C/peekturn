# Task context

Load the owner for the affected work, not every feature directory.

- EPUB import, library, navigation, restoration, typography, reader chrome or reading-time statistics: [reading](reading/AGENTS.md).
- Selection actions, Quick Explain, provider profiles, explanation streaming, popup or offline dictionary: [learning](learning/AGENTS.md).
- Word recordings, Android speech, voice availability, autoplay or audio focus: [pronunciation](pronunciation/AGENTS.md).
- Product scope, shared visual design or cross-feature acceptance: [product specification](SPEC.md).
- Before runtime verification or claims about tested behavior: [verification evidence](verification/VERIFICATION.md), including its remaining evidence boundaries and the relevant dated update. Historical speech/theme/popup behavior is not the current product contract.
