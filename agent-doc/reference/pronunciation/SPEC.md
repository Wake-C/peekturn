# Pronunciation requirements

Single-word pronunciation first requests a freely licensed recording in the preferred US/UK accent from Wikimedia Commons. Only the word is sent, never its context, book titles or model credentials. Use actual source metadata and audio URLs, not guessed commercial dictionary URLs. Coverage and network access are not guaranteed. Display the recording's creator, source and license with source/license links; recordings are not LLM-generated and are not bundled as app-owned assets.

If no usable recording is available, speak the exact selected term with an installed English system voice. Phrases and complete examples go directly to Android TextToSpeech, never an online word lookup. Prefer usable offline English, requested accent when available; another installed English accent or generic English is a valid fallback with a nonblocking notice. A country mismatch alone is not an installation error. Never select a non-English voice. Try standard language selection when enumeration is empty or rejects candidates. Distinguish genuinely missing English data, unavailable engine and playback failure. Refresh capabilities on retry after system settings. No microphone permission.

Manual term speaker is available before AI completes. Playback toggles Stop; a new utterance replaces rather than queues. Auto-pronounce is global, off by default, once per new lookup across Explain/Dictionary. Switching tabs or retrying does not repeat it. Stop on close, adjust, leaving reader, or background. Late initialization/callbacks cannot play obsolete text. Release resources and respect audio focus/media routing.
